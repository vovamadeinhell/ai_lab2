# Лабораторная работа №2

Системы искусственного интеллекта. Экспертная система с обратной цепочкой рассуждений.
Предметная область — диагностика неисправностей компьютера.

## Запуск

Требуется Python 3.10 или новее, сторонние библиотеки не нужны.
Из папки с файлами лабораторной работы: `python3 main.py`.
Если открыт общий проект с двумя лабораторными, сначала выполните `cd lab2`.
В PyCharm откройте `main.py` этой лабораторной и нажмите Run.

## Работа с программой

1. Выберите пункт 1.
2. Задайте начальную рабочую базу: вводите факты `Объект=Значение`, затем пустую строку. Можно задать пустую базу.
3. Выберите целевую ситуацию: номер диагноза из списка или произвольную пару `Объект=Значение`.
4. Укажите, нужно ли запрашивать неизвестные исходные факты: `да` или `нет`. При ответе на вопрос пустая строка означает неизвестное значение.
5. Программа покажет ход доказательства, итоговую рабочую базу и результат.

Имена и значения чувствительны к регистру. Для признаков используйте `да` и `нет`.
Начальные факты действуют в пределах одной консультации. Выведенные факты не меняют файл правил.

## База знаний

В `rules.txt` находится отдельная копия 20 правил лабораторной №1.
Формат: `ЕСЛИ условие=значение И другое_условие=значение ТО заключение=значение`.
Меню позволяет просматривать, добавлять, изменять и удалять правила с сохранением в файл.
Новые признаки и цели обрабатываются без изменения программы.
Для каждого объекта рабочая база хранит одно значение. При повторном вводе начального объекта используется последнее введённое значение.

## Алгоритм

Обратный вывод идёт от цели к условиям: выбираются правила с нужным заключением, а каждое условие становится подцелью. Условия одного правила соединены через И, альтернативные правила — через ИЛИ. Подтверждённые заключения добавляются в рабочую память. Известный факт с другим значением отклоняет ветвь. При неудаче программа пробует следующее правило. Повтор цели в текущей ветви останавливает цикл, сохраняя возможность проверить альтернативы.

Вопросы задаются только об исходных объектах, которые не встречаются в заключениях правил. Промежуточные факты доказываются правилами.

Результат имеет три состояния:

- **Доказано** — существует подтверждённая цепочка к цели.
- **Недостижимо** — все цепочки отклонены при заданных фактах и правилах. Это вывод относительно текущей базы знаний.
- **Недостаточно данных** — часть необходимых исходных фактов неизвестна; отсутствие сведений не считается опровержением.

## Пример начального состояния и цели

Начальные факты:

```text
Компьютер_включается=да
Экран_черный=да
Звук_загрузки=да
Изображение_на_мониторе=нет
```

Цель: `Диагноз=проверить_видеокарту_кабель_и_монитор`.
Поиск идёт через правила 8 → 5 → 1. Подтверждение условий позволяет применить правила в порядке 1 → 5 → 8. Цель доказана.
Если заменить `Звук_загрузки=да` на `Звук_загрузки=нет`, цель недостижима.
Если оставить начальную базу пустой и отключить вопросы, результат — недостаточно данных.
Полные реальные запуски этих трёх сценариев находятся в `sample_run.txt`.

## Проверка

Из папки с файлами лабораторной работы: `python3 -m unittest -v`.
Семь тестов проверяют многошаговое доказательство, противоречие, неполные данные, запрос исходных фактов, циклы и альтернативные правила, а также отдельную ветвь диагностики питания.
